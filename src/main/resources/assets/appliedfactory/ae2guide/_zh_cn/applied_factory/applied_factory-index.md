# 应用工厂

应用工厂让你用 TypeScript 控制 AE2 网络中的机器，并把机器加工注册为 AE2 可自动合成的加工样板。

## 快速开始

1. 放置工厂控制器，并用 AE2 线缆连接控制器需要使用的面。
2. 在机器旁的 AE2 线缆上安装工厂总线，让总线正对机器。
3. 执行 `/appliedfactory setupworkspace` 准备脚本文件和当前整合包的配方数据。
4. 打开控制器，从左侧选择 TypeScript 文件。
5. 编辑脚本并点击 `↑` 上传。
6. 检查日志；脚本成功注册样板后，即可在 AE2 终端中发起合成。
